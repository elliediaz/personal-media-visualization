# 샘플 오디오 파일

이 디렉토리는 테스트 및 예제용 샘플 오디오 파일을 저장하는 곳입니다.

## 사용 방법

1. 테스트용 오디오 파일을 이 디렉토리에 추가하세요
2. 예제 코드에서 사용할 수 있습니다

## 권장 파일

예제 및 테스트를 위해 다음과 같은 샘플 파일을 준비하는 것이 좋습니다:

- `sample.mp3`: 기본 테스트용 MP3 파일
- `sample.wav`: WAV 포맷 테스트용
- `sample.flac`: FLAC 포맷 테스트용
- `sample.ogg`: OGG 포맷 테스트용

## 저작권 안내

샘플 파일은 반드시 다음 중 하나를 사용하세요:

1. 본인이 직접 제작한 오디오
2. 공개 도메인(Public Domain) 오디오
3. 크리에이티브 커먼즈 라이선스 오디오
4. 테스트 목적으로 사용 가능한 오디오

## 참고사항

- 이 디렉토리의 오디오 파일은 `.gitignore`에 의해 Git에 추적되지 않습니다
- 대용량 파일은 프로젝트 저장소에 포함되지 않습니다
- 테스트 시 실제 오디오 파일을 직접 추가해야 합니다
